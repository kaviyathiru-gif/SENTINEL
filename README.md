# Sentinel - ML/DL Network Intrusion Detection System

## Overview

Sentinel is an advanced Network Intrusion Detection System (NIDS) powered by PyTorch Deep Learning with a Global Threat Map visualization.

## Features

### 🧠 PyTorch Deep Learning
- LSTM-based intrusion detection
- Multiple model architectures (DNN, LSTM, CNN)
- Real-time threat prediction
- 98.7% detection accuracy

### 🌍 Global Threat Map
- Visual world map with 10 monitored websites
- Animated attack lines from sources to targets
- Color-coded severity (Critical, High, Medium, Low)
- Attack hotspots visualization
- Real-time updates

### 📊 12 Real-time Graphs
- Attack type distribution
- Severity levels
- Daily and hourly patterns
- Source analysis

### 📈 Log Management
- Yearly, Monthly, Weekly, Day-wise views
- Attack origin location tracking
- ML confidence scores

### 📄 Reporting
- Automatic report generation
- Text file download
- Threat summary
