## 📌 Executive Summary

**SENTINEL** is an elite, multi-domain cyber defense platform designed to provide real-time network telemetry, automated threat mitigation, and visual UI tamper protection. Built with a dark neon purple and cyan aesthetic, Sentinel brings together WebXR 3D spatial scanning, deep neural threat evaluation, computer vision layout safeguards, and multi-tier emergency voice call escalation.

---

## 🚀 Key Features

* **3D AR Quantum Threat Globe:** Built on Three.js (r128), featuring an 8D Quantum Hyper-Matrix layer, dynamic ballistic Bezier threat arcs, and interactive node pin tracking.
* **Google Satellite GIS Integration:** Real-time spatial locking that maps selected threat nodes directly to high-resolution Google Satellite maps, pinning attacker coordinates, IP addresses, and vector signatures.
* **10-Domain Monitored Slot Manager:** Dynamic expansion allowing security analysts to monitor up to 10 concurrent web application domain slots with live URL validation and 10-workspace mobile swipe gestures.
* **Computer Vision DOM Tamper Guard:** Real-time spatial tracking monitoring UI element coordinates to detect layout drift, unauthorized drag attempts, or deepfake visual alterations, automatically rectifying shifted components.
* **13 Power BI Analytics Visualizations:** Powered by Chart.js, featuring scatter plots, polar malware distributions, network throughput line charts, and the flagship KDD-Cup Deep Neural Net precision matrix.
* **Automated Emergency Call Escalation:** Node.js integration with Twilio Programmable Voice to dispatch real phone calls to Priority 1 Admins, automatically failing over to Priority 2 and 3 SOC leads if unanswered within 10 seconds.
* **Automated Gmail Incident Reports:** Node.js + Nodemailer pipeline generating PDF security receipts and dispatching daily, weekly, and monthly comparison metrics directly to the Admin’s Gmail account.
